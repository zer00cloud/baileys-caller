# Source Map

## baileys-caller Outbound

| Action | File | Function |
| --- | --- | --- |
| Connect Baileys socket | `src/index.mts` | `VoipClient.connect()` |
| Initialize signaling bridge | `src/index.mts` | `new SignalingBridge()`, `SignalingBridge.init()` |
| Initialize WASM | `src/index.mts`, `src/wasm-engine.mts` | `new WasmEngine()`, `initialize()` |
| Initialize VoIP stack | `src/index.mts`, `src/wasm-engine.mts` | `initVoipStack()` |
| Create outbound call object | `src/index.mts` | `VoipClient.call()` |
| Resolve LID / devices / sessions | `src/signaling.mts` | `resolveLid()`, `discoverPeerDevices()`, `ensureSessionsForPeers()` |
| Start call / generate offer | `src/wasm-engine.mts` | `startCall()` -> WASM `startVoipCall()` |
| Send signaling generated by WASM | `src/index.mts`, `src/signaling.mts` | `onSignalingXmpp`, `sendSignaling()` |
| Encrypt offer / enc_rekey | `src/signaling.mts` | `#encryptCallKey()` |
| Send call stanza | `src/signaling.mts` | `#sendCallStanza()` |
| Process remote answer/transport/etc. | `src/signaling.mts`, `src/wasm-engine.mts` | `processIncomingCall()`, `handleSignalingMessage()` |
| Relay network setup | `src/relay-transport.mts` | `RelayRtcTransport.updateRelayList()`, `send()` |
| Send PCM | `src/audio-feeder.mts`, `src/index.mts`, `src/wasm-engine.mts` | `AudioFeeder`, `#handleAudioCaptureStart()`, `sendAudioData()` |
| Receive PCM | `src/wasm-engine.mts`, `src/index.mts` | `requestAudioDataFromWasmVoip()`, `_emitAudio()` |
| Hang up | `src/index.mts`, `src/wasm-engine.mts` | `ActiveCall.end()`, `endCall()` |
